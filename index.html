Read This First: What Is Truly Automatic

✅ Claude does well

Niche research, topic calendars, scripts, titles, descriptions, tags, thumbnail ideas, checklists, weekly reports, and running a recurring task on a schedule.

🧩 Needs a helper tool

Voice recording, video rendering and the actual upload. Claude writes or runs the code, but a tool such as ffmpeg, Remotion, a text-to-speech service or the YouTube API does the work.

👤 Keep a human

A quick review before publishing: facts, tone and copyright. Fully unattended channels risk errors and policy trouble.

Network warning. A Claude cloud scheduled task may run in a sandbox that blocks calls to Google's servers. Test one upload first. If it is blocked, run the task on your own computer (desktop scheduled task) or let Claude prepare files and use GitHub Actions or n8n for the upload step. Section 6 shows all three options.
YouTube policy. Channels that post repetitive, mass-produced videos with no original value can lose monetization. Add your own voice, examples or analysis. Mark AI-altered realistic content with the "altered or synthetic content" setting. Check the current YouTube Partner Program policy before you scale.

One-Time Setup (about 1 hour)

  1. Create or choose a YouTube channel. Verify it with your phone number so custom thumbnails and longer videos work.
  2. Open Google Cloud Console and create a project named youtube-automation.
  3. Enable "YouTube Data API v3" under APIs and Services, then Library.
  4. Set up the OAuth consent screen and add yourself as a test user.
  5. Create OAuth client credentials of type "Desktop app". Download the file and save it as client_secret.json.
  6. Run the first login once. A browser opens, you approve the youtube.upload permission, and a token.json file is saved for all future runs.
  7. Request the API compliance audit for your Google Cloud project when you are ready to go public.
Important. Google's documentation says videos uploaded from unverified API projects created after 28 July 2020 are restricted to private viewing until the project passes an audit. Until then, your scheduled videos stay private, and you can publish them by hand in YouTube Studio.

The Upload Script (Python)

Ask Claude to save this as upload.py and install the libraries with pip install google-api-python-client google-auth-oauthlib.

import os
from google_auth_oauthlib.flow import InstalledAppFlow
from google.auth.transport.requests import Request
from google.oauth2.credentials import Credentials
from googleapiclient.discovery import build
from googleapiclient.http import MediaFileUpload

SCOPES = ["https://www.googleapis.com/auth/youtube.upload"]

def get_service():
    creds = None
    if os.path.exists("token.json"):
        creds = Credentials.from_authorized_user_file("token.json", SCOPES)
    if not creds or not creds.valid:
        if creds and creds.expired and creds.refresh_token:
            creds.refresh(Request())
        else:
            flow = InstalledAppFlow.from_client_secrets_file(
                "client_secret.json", SCOPES)
            creds = flow.run_local_server(port=0)
        with open("token.json", "w") as f:
            f.write(creds.to_json())
    return build("youtube", "v3", credentials=creds)

def upload(video, title, description, tags, publish_at_utc,
           category="27", made_for_kids=False):
    yt = get_service()
    body = {
        "snippet": {"title": title, "description": description,
                    "tags": tags, "categoryId": category},
        "status": {
            "privacyStatus": "private",
            "publishAt": publish_at_utc,   # e.g. 2026-12-07T03:00:00Z
            "selfDeclaredMadeForKids": made_for_kids,
            "containsSyntheticMedia": False,  # True if realistic AI media
        },
    }
    media = MediaFileUpload(video, chunksize=8 * 1024 * 1024,
                            resumable=True)
    req = yt.videos().insert(part="snippet,status",
                             body=body, media_body=media)
    resp = None
    while resp is None:
        status, resp = req.next_chunk()
        if status:
            print(f"Uploaded {int(status.progress() * 100)}%")
    print("Video ID:", resp["id"])
    return resp["id"]

if __name__ == "__main__":
    upload("output/2026-12-07.mp4",
           "My first automated video",
           "Description here",
           ["ai", "tutorial"],
           "2026-12-07T03:00:00Z")

📊 Limits to know

Several 2026 guides report that uploads now have their own bucket of 100 calls per day at 1 unit each, while videos.update and thumbnails.set cost 50 units each. Older guides still say 1,600 units per upload. Check the Quota Calculator in your own Google Cloud project, since this changed recently. YouTube also has a separate per-channel daily upload cap.

🛡️ Keep it safe

Never paste client_secret.json or token.json into a chat or a public repository. Store them in a private folder or in your automation tool's secret storage.

Schedule Everything from Claude

Claude scheduled tasks run a saved prompt on a repeating schedule (hourly, daily, weekly) using your connectors and files. Cloud tasks keep running when your computer is off. Pick the setup that fits your upload step.

Option A: Desktop task

Best for: beginners.

The task runs on your own computer, so it can reach YouTube, ffmpeg and your files. The computer and the Claude desktop app must be on at the run time.

Option B: Claude prepares, a tool uploads

Best for: fully hands-off.

A cloud Claude task writes the script and metadata into a folder or sheet. GitHub Actions, n8n or Make then renders and uploads on a timer.

Option C: Hybrid weekly batch

Best for: quality control.

Once a week Claude prepares 7 videos. You review them in 20 minutes. The upload script then schedules all 7 with publishAt.

Create the task: 4 taps
  1. Open Scheduled in the Claude sidebar (or claude.ai/code/scheduled for the web version).
  2. Tap New task and choose Create with Claude, or set it up manually.
  3. Paste the prompt below, choose Daily and a time, and pick your folder.
  4. Save, then use Run now once to test before trusting it.

Ready-made scheduled task prompt

You run my YouTube channel pipeline. Each run:
1. Open calendar.csv and pick the first row with
   status = "ready" and a date within the next 7 days.
2. Write the script using CHANNEL_BRIEF.md and mark
   facts that need checking with [CHECK].
3. Create script.json, metadata.json and the
   thumbnail prompt in output/<date>/.
4. Build the video with build_video.py.
5. If every [CHECK] is resolved, run upload.py with
   publish time from the calendar. Otherwise set
   status = "needs review" and stop.
6. Update calendar.csv: status, video ID, errors.
7. Write a 5-line summary of what happened.
Never publish anything with unresolved [CHECK] items.
Never delete files.
Why the review gate matters. The prompt stops and flags anything unverified. This single rule protects your channel from wrong facts and policy strikes.
